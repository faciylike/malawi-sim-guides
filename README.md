## ⚙️ 关键设置：让手机活起来
　　买卡只是第一步，设置对了才能上网！这步卡住的人真不少：
*   **APN设置（重中之重！）**：
    *   **Airtel**： `internet.airtel.mw` (新卡通常自动配置，但手动检查最保险)
    *   **TNM**： `internet` 或 `tnm.net`
    *   *手动设置在哪？* Android在“移动网络”-“接入点名称(APN)”；iOS在“蜂窝网络”-“蜂窝数据选项”-“蜂窝数据网络”。找不到？问店员或当场搜！
